# Mesh facet

Attach, query, and clear a neuron surface mesh on a single tree
(``tree.mesh``). Also bound as methods on
{class}`~neurosetta.api.tree_class.Tree`.

``Tree_mesh`` is the I/O / payload type — preferred workflow is attach and work
from the Tree (see {doc}`../../tutorials/meshes`).

Forest batch attach by ID: {func}`~neurosetta.ops.forest_ops.forest_meshes.set_meshes`
(bound as ``Forest.set_meshes``).
