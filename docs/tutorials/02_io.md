# Import and export

NeuRosetta reads and writes three main formats:

| Format | Functions | Typical use |
|--------|-----------|-------------|
| **SWC** | `import_swc`, `export_swc` | Standard morphology exchange |
| **NR** | `save`, `load` | Native graph-tool based `.nr` files |
| **Mesh** | `import_mesh`, `export_mesh` | Neuron / neuropil surfaces via vedo |

Sample SWC files ship with the docs in `docs/data/`.

## Paths used in these tutorials

From the repository root:

```python
from pathlib import Path
import NeuRosetta as nr

DATA = Path("docs/data")
```

## Import a single SWC file

SWC file stems must be **integer IDs** (for example `1.swc` → tree ID `1`):

```python
tree = nr.import_swc(DATA / "1.swc")
print(tree.ID, type(tree))
print(tree.metadata)
```

Default metadata includes `file_path`, `units` (initially `"undefined"`), and
`isReduced`.

## Import a directory of SWC files

Passing a directory returns a {class}`~NeuRosetta.api.Forest`:

```python
forest = nr.import_swc(DATA, progress=True)
print(len(forest), forest.ids())
```

Use `parallel=True` for larger folders.

## Export SWC

```python
from pathlib import Path
import tempfile

out = Path(tempfile.mkdtemp())
nr.export_swc(tree, out / "1.swc")
# or:
tree.export_to_swc(out / "1.swc")
```

For a forest, pass a directory:

```python
nr.export_swc(forest, out / "swc_out", progress=True)
```

## Native `.nr` files

`.nr` files store graph-tool graphs and are convenient for round-tripping
NeuRosetta objects:

```python
nr.save(tree, out / "1.nr")
# or:
tree.save_tree(out / "1.nr")

reloaded = nr.load(out / "1.nr")
print(reloaded.count_nodes() == tree.count_nodes())
```

Saving a forest writes one `.nr` file per tree ID into a directory:

```python
nr.save(forest, out / "nr_out")
forest2 = nr.load(out / "nr_out")
print(forest2.ids())
```

## Mesh I/O

Meshes are loaded through vedo. Choose the object type with `mesh_type`:

```python
# neuron surface → Tree_mesh / Forest_mesh
# neuron_mesh = nr.import_mesh("neuron.ply", mesh_type="Neuron")

# neuropil surface → Neuropil / Neuropils
# neuropil = nr.import_mesh("neuropil.ply", mesh_type="Neuropil")

# nr.export_mesh(neuropil, "out/neuropil.ply")
```

Default export format is **binary PLY** (`.ply`). Other formats supported by
vedo (OBJ, STL, VTK, …) can be selected via the output path / `fileoutput`
argument.

## What to remember

- SWC stems must parse as integers.
- File → single object; directory → collection (`Forest` / `Forest_mesh` /
  `Neuropils`).
- Prefer `.nr` for NeuRosetta-native workflows; use SWC for interoperability.
